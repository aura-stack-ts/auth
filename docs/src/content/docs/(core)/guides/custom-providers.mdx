---
title: Custom OAuth Providers
description: Define and extend OAuth providers in Aura Auth
---

Aura Auth provides **fully compliant support** for the [OAuth 2.0 Authorization Framework](https://datatracker.ietf.org/doc/html/rfc6749) and [OpenID Connect](https://openid.net/specs/openid-connect-core-1_0.html). This allows Aura Auth to integrate with a wide range of third-party services and identity providers.

To minimize setup time and reduce implementation risk, Aura Auth ships with a growing set of **built-in OAuth providers** for widely used third-party services (such as GitHub, GitLab, X, Spotify, and others). Read the [OAuth Providers](/docs/oauth) guide for a complete list of supported providers.

However, some organizations rely on **internal OAuth servers** or providers that are not included by default. For these cases, Aura Auth allows **custom OAuth providers** to be defined while preserving the same security guarantees and integration model.

## Adding a Custom OAuth Providers

If a required OAuth provider is not included, Aura Auth allows defining a fully custom provider.

To do so, the provider must conform to the `OAuthProviderCredentials` interface. This interface defines the OAuth endpoints, client credentials, scopes, and optional profile mapping logic. For all available fields, see [OAuthProvider API Reference](/docs/api-reference/core#oauth)

### OAuth Provider

Use the `OAuthProvider` type to define a custom OAuth provider. The following table describes the available fields:

| Name            | Type                                | Description                                                                          |
| --------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `id`            | `string`                            | Unique identifier for the provider.                                                  |
| `name`          | `string`                            | Human-readable name for the provider.                                                |
| `authorize`     | `string` \| `object`                | OAuth authorization endpoint configuration`.                                         |
| `accessToken`   | `string` \| `object`                | OAuth access token endpoint URL.                                                     |
| `userInfo`      | `string` \| `object`                | OAuth user info endpoint URL.                                                        |
| `refreshToken`  | `string` \| `object`                | OAuth refresh token endpoint URL.                                                    |
| `revokeToken`   | `string` \| `object`                | OAuth revoke token endpoint URL.                                                     |
| `refreshWindow` | `number`                            | Time in seconds before the access token expires to attempt a refresh.                |
| `scope`         | `string`                            | OAuth scopes to request during authorization.                                        |
| `profile`       | `(profile: Profile) => DefaultUser` | Optional function to map the provider's user profile to Aura Auth's expected format. |

```ts title="@/lib/auth.ts" lineNumbers
import type { User } from "@aura-stack/auth"
import type { OAuthProvider } from "@aura-stack/auth/types"

interface CustomProvider {
  id: number
  username: string
  email: string
  name: string
  avatar_url: string
}

const provider: OAuthProvider<CustomProvider, User> = {
  id: "custom",
  name: "Custom Provider",
  authorize: {
    url: "https://custom.com/authorization",
    params: {
      scope: "user:email user:profile",
      responseType: "code",
    },
  },
  accessToken: "https://custom.com/access_token",
  userInfo: "https://api.custom.com/v1/user",
  profile(profile) {
    return {
      sub: profile.id.toString(),
      name: profile.name,
      email: profile.email,
      image: profile.avatar_url,
    }
  },
}
```

The `profile` function is responsible for returning a stable and unique sub identifier, which is used internally for session and user identity.

### OpenID Connect Provider

| Name            | Type                                | Description                                                                          |
| --------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `id`            | `string`                            | Unique identifier for the provider.                                                  |
| `name`          | `string`                            | Human-readable name for the provider.                                                |
| `issuer`        | `string`                            | OpenID Connect issuer URL.                                                           |
| `refreshWindow` | `number`                            | Time in seconds before the access token expires to attempt a refresh.                |
| `revokeToken`   | `string`                            | OpenID Connect revoke token endpoint URL.                                            |
| `scope`         | `string`                            | OpenID Connect scopes to request during authorization.                               |
| `profile`       | `(profile: Profile) => DefaultUser` | Optional function to map the provider's user profile to Aura Auth's expected format. |

```ts title="@/lib/auth.ts" lineNumbers
import type { User } from "@aura-stack/auth"
import type { OAuthProvider } from "@aura-stack/auth/types"

interface CustomProvider {
  id: number
  username: string
  email: string
  name: string
  avatar_url: string
}

const provider: OAuthProvider<CustomProvider, User> = {
  id: "custom",
  name: "Custom Provider",
  issuer: "https://custom.com",
  revokeToken: "https://custom.com/revoke_token",
  scope: "openid profile email",
  profile(profile) {
    return {
      sub: profile.sub,
      name: profile.name,
      email: profile.email,
      image: profile.avatar_url,
    }
  },
}
```
